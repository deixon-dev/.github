# deixon-dev

We build **deixon**: point it at existing code or a prose requirements document, and it builds
formal models, runs the TLC and Alloy model checkers, and reports temporal and structural bugs —
or gaps and contradictions — in your own terms.

- Tool repository: [deixon-dev/deixon](https://github.com/deixon-dev/deixon)
- Python package: [deixon-engine on PyPI](https://pypi.org/project/deixon-engine/)
